# Isaac Online

Кооперативный браузерный раннер в духе Binding of Isaac x Madness Combat.
Полностью статический сайт (HTML/CSS/JS, без сборки и без своего сервера) —
мультиплеер работает напрямую между браузерами игроков через WebRTC (библиотека PeerJS).

## Структура проекта

```
isaac-online/
├── index.html        — разметка (лобби + игровой экран)
├── css/style.css      — стили
└── js/
    ├── main.js        — точка входа, связывает всё вместе
    ├── config.js      — персонажи, враги, комнаты, апгрейды
    ├── game.js         — главный класс игры (логика режимов solo/host/guest)
    ├── sim.js          — авторитетная симуляция (враги, урон, комнаты) — считается у хоста
    ├── net.js          — сетевой слой (PeerJS/WebRTC)
    ├── render.js        — отрисовка на canvas
    ├── physics.js, world.js, rng.js — вспомогательная логика
    ├── audio.js         — звуки (WebAudio)
    ├── input.js         — клавиатура/мышь/тач
    └── ui.js            — работа с DOM (лобби, HUD, чат, оверлеи)
```

## Как это работает

- Один игрок жмёт **«Создать комнату»** — его браузер становится хостом и считает всю
  логику (комнаты, врагов, урон). Он получает 6-значный код комнаты.
- Другой игрок вводит этот код и жмёт **«Войти»** — устанавливается прямое P2P-соединение
  (WebRTC) через бесплатный сигнальный сервер PeerJS Cloud. Дальше весь игровой трафик
  идёт напрямую между браузерами, без вашего сервера.
- Можно играть и в одиночку — кнопка **«Играть соло»**.
- До 4 игроков в одной комнате.

## Запуск локально

Это обычный статический сайт, поэтому достаточно любого HTTP-сервера в папке проекта, например:

```bash
npx serve .
# или
python3 -m http.server 8000
```

и открыть `http://localhost:8000` (или порт, который выведет команда) в браузере.

Открывать `index.html` напрямую через `file://` **не получится** — ES-модули (`<script type="module">`)
браузеры блокируют без HTTP(S). Обязательно нужен локальный сервер.

## Деплой на Vercel

1. Залейте папку `isaac-online/` в репозиторий на GitHub.
2. На vercel.com → **Add New → Project** → выберите этот репозиторий.
3. Framework Preset — **Other** (это статический сайт, сборка не нужна).
   Build Command и Output Directory можно оставить пустыми — Vercel сам отдаст `index.html`.
4. Deploy. Готово — ссылку можно отправлять друзьям.

То же самое сработает и на GitHub Pages: Settings → Pages → Deploy from branch → `/ (root)`.

## Известные ограничения

- Мультиплеер использует бесплатный публичный TURN-сервер (openrelay.metered.ca) как
  запасной вариант для «строгих» сетей (мобильный интернет, корпоративный Wi-Fi). В 80–90%
  случаев подключение и так проходит напрямую через STUN. Если у друга не получается зайти
  в комнату именно в такой сети — попробуйте другую сеть или получите свои бесплатные TURN-
  креды на metered.ca и подставьте их в `js/net.js` (массив `ICE_SERVERS`).
- Комнаты не сохраняются на сервере: если хост закрывает вкладку, комната закрывается для всех.

## Что изменено/добавлено относительно исходного файла

- **Исправлено:** оригинал был завязан на Firebase Firestore со служебными переменными
  окружения конкретной песочницы (`__firebase_config` и т.п.) — на обычном GitHub Pages/Vercel
  он просто не запускался. Мультиплеер полностью переписан на WebRTC (PeerJS), который
  работает на любом статическом хостинге без своего бэкенда.
- **Исправлено:** движение по WASD теперь читается по физическому коду клавиши (`event.code`),
  а не по символу — работает при любой раскладке клавиатуры.
- **Исправлено:** читкод `MADNESS` в оригинале ничего не делал — теперь реально даёт двойной
  урон и скорострельность (плюс два новых кода: `GOD` и `SPEED`).
- **Добавлено:** настоящая боевая система — 5 типов врагов со своим ИИ (в т.ч. босс),
  урон, смерть, лут (сердца/монеты/апгрейды), полная зачистка комнат.
- **Добавлено:** совместное прохождение — если один игрок погиб, при зачистке комнаты
  его воскрешает напарник.
- **Добавлено:** прицеливание мышью (клик в сторону курсора), помимо клавиш-стрелок и тач-кнопок.
- **Добавлено:** миникарта с учётом тумана войны и позиций других игроков в реальном времени.
- **Добавлено:** система прокачки (урон/скорострельность/скорость/HP/дальность) через сундуки и лут.
